# casa-lab
Personal IT infrastructure lab for Windows Server, Active Directory, networking, PowerShell, and cloud administration.

## Lab Environment

- Hypervisor: VMware Workstation Pro 26H1
- Windows Server: Windows Server 2025
- Host: Lenovo Slim 7i
- Network: NAT
